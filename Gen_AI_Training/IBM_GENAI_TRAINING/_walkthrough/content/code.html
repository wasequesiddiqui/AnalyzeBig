In one breath

Eight files, one theme: getting the right text in front of a language model. You will see a credential health-check, five different retrieval strategies on the same ten sentences, a complete question-answering pipeline over a company-policy file, a two-tool AI agent, a hand-written distance matrix, and two leftovers (an empty file and a scratch probe).

Read in this orderLANGCHAIN_APP_BASICS.py first (credentials), then RAG_BASIC.py (the whole RAG loop), then advanced_retrievers.py (retrieval options), then the rest.
What is RAG, really?Ask a librarian for a book (retrieval), then ask a teacher to answer your question using only that book (generation). Without retrieval the teacher answers from memory and invents details.

Think of an IRCTC enquiry counter

You ask an enquiry clerk: "Which train from Kanpur reaches Delhi before 9 am?" A good clerk does not memorise every timetable - they open the register, find the three relevant rows, and explain them to you. That is retrieval-augmented generation: the register is the vector database, the clerk is the LLM, and the answer is only as good as the rows they picked.

The files in this folder are the different ways of searching that register:

  • Vector search - "trains similar to what I described" (nearest embeddings).
  • BM25 - "rows containing exactly the words I typed" (a smarter Ctrl+F).
  • Multi-query - ask the clerk to write down five versions of your question first.
  • Self-query - "only trains departing after 6 pm" - filter first, then search.
  • Parent-document - search by the index card, then hand you the whole file.

Before you run anything

Credentials - create a .env next to the files with exactly these three names:

WATSONX_URL=https://eu-de.ml.cloud.ibm.com
WATSONX_PROJECT_ID=your-project-id
WATSONX_APIKEY=your-api-key

Values are never printed in this page. The URL must be the region where your project actually lives: us-south, eu-gb, eu-de or jp-tok.

Fail fast, fail clearlyAlmost every "it doesn't work" in this folder is a missing environment variable, a wrong region, or a project id copied from course material. Run the handshake file first and fix that before touching retrieval code.
