🌟 Why `universal_chain` is the heart

  • Single entry point – any user query becomes a clean, consistent pipeline.
  • Automates recursion – tool execution + LLM re-invocation handled automatically.
  • Universal + reusable – swap tools (SQL, RAG, web search) without changing orchestration.
  • Production ready – modular, parallel execution, easy debugging.

🔄 Recursive Chain Logic

process_tool_calls()

Executes all tool calls from last AI message (parallel), creates ToolMessages, reinvokes LLM, returns updated message history.

def process_tool_calls(messages):
  tool_msgs = [execute_tool(tc) for tc in last_msg.tool_calls]
  updated = messages + tool_msgs
  next_ai = llm_with_tools.invoke(updated)
  return updated + [next_ai]

_recursive_chain()

Checks if last message contains tool_calls → recursively calls process_tool_calls until stop condition, building full conversation.

def _recursive_chain(messages):
  if should_continue(messages):
    return _recursive_chain(process_tool_calls(messages))
  return messages
Parallel tool execution reduces latency · recursion depth automatically managed · final answer extracted via get_final_response()

📜 Full Python Implementation (core architecture) 
# === UNIVERSAL RECURSIVE AGENT (YouTube) ===
# Tools: extract_video_id, fetch_transcript, search_youtube, get_full_metadata, get_thumbnails

llm_with_tools = ChatOpenAI(model="gpt-4o-mini").bind_tools(tools)

def execute_tool(tool_call):
    result = tool_mapping[tool_call["name"]].invoke(tool_call["args"])
    return ToolMessage(content=json.dumps(result), tool_call_id=tool_call["id"])

def process_tool_calls(messages):
    tool_msgs = [execute_tool(tc) for tc in messages[-1].tool_calls]
    updated = messages + tool_msgs
    return updated + [llm_with_tools.invoke(updated)]

def _recursive_chain(messages):
    if messages[-1].tool_calls:
        return _recursive_chain(process_tool_calls(messages))
    return messages

universal_chain = (
    RunnableLambda(lambda x: [HumanMessage(content=x["query"])])
    | RunnableLambda(lambda msgs: msgs + [llm_with_tools.invoke(msgs)])
    | RunnableLambda(_recursive_chain)
)

# Execution: messages = universal_chain.invoke({"query": user_input})
