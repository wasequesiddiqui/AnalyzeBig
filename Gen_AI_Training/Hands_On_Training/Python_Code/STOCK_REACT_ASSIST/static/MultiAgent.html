Multi-Agent Valuation Crew

Every persona, agent and function in PERSONA_AGENTS_CREW.py

5 agents · 3 tools · 36 symbols
◆
A standalone crewAI crew that runs four investor-persona agents — each dedicated to a famous investor — plus a lead-analyst agent that reconciles them. Every persona researches autonomously (ReAct-style tool calling over DeepSeek), emits one JSON fair-value judgement, and the lead produces a consensus range. The rule-based range from PERSONA_BASED_VALUATION.py is computed alongside so the two methodologies can be compared.

B

The crewAI pattern

parallel experts, then a lead
Crew( agents = [persona_1, persona_2, persona_3, persona_4, lead_agent], tasks = [persona_1_task, ..., persona_4_task, lead_task], process = Process.sequential, ) # the four persona tasks run CONCURRENTLY: Task(name=f"persona_{key}", agent=..., async_execution=True) # the lead task receives all four as CONTEXT: Task(name="aggregator_task", agent=lead_agent, context=persona_tasks)

Process.sequential combined with async_execution=True on the persona tasks is crewAI's idiom for "run N experts in parallel, then have a lead reconcile them". The lead agent is built with no tools at all and gets the four answers purely through Task.context — so it cannot fetch anything that would contradict the committee it is summarising.

Outputs are mapped back by Task.name (persona_warren_buffett, persona_charlie_munger, …, aggregator_task) via result.tasks_output[i].raw.

Design principles

why it is built this way
01

Error isolation

A failing persona yields an empty card plus a line in errors; the other three still render. Only an unresolvable ticker raises.

_snapshot_or_raise · errors[]
02

No LangChain

Every data path is a thin wrapper over a plain function in this module, so there are no langchain_* imports to keep in sync.

PERSONA_TOOLS
03

Low variance

temperature=0 plus "work silently, emit JSON only" prompts keep token cost and output shape stable.

get_llm · RESPONSE CONTRACT
04

Yahoo rate-limit shield

One run would otherwise fire 15+ Yahoo requests (all four personas fetch the same statements). A TTL cache collapses them to one fetch per ticker.

_memoise · _CACHE_TTL_SECONDS
05

Headless-friendly

Never imports the Streamlit entrypoint, and the cache is deliberately not st.cache_data, so it runs under pytest and the CLI.

_cache_get · _memoise
06

Plausibility guard

A persona reporting revenue or market cap instead of a per-share value is caught: any figure outside 0.1×–8× the live price is discarded.

GotchaDetail
Windows consolescrewAI's event bus prints emoji/₹/≈ and crashes a cp1252 console. This module reconfigures stdout/stderr to UTF-8 at import — and that must run before import crewai, so the top-of-file ordering is load-bearing.
Chain-of-thought blowupsWithout the "work silently" clause DeepSeek writes a 400-line DCF into its final answer, breaking the JSON parse and multiplying token cost.
Currency mismatchDual-listed Indian names report financials in USD but trade in INR. Personas are told to answer in the market-price currency, and an FX note carries the rate.
Yahoo betaFrequently wrong for non-US large caps (INFY ≈ 0.11); the prompts tell the persona to substitute a sensible industry beta rather than spiral.
Agents are PydanticIn crewAI 1.x, Agent / Task / Crew / LLM are Pydantic v2 models — pass keyword arguments only.
Degenerate rule rangeFor some symbols the rule-based model returns min == max == mid (a pre-existing issue in PERSONA_BASED_VALUATION, not here). MIN_DETERMINISTIC_PERSONAS = 1 keeps the comparison visible when only one rule prices.

Post-processing guard

persona_from_raw
\[ \text{keep } fv \iff 0.1 \cdot P_{market} \;\le\; fv \;\le\; 8 \cdot P_{market} \]

A persona that reports revenue ("$20,158M") or market capitalisation instead of a per-share value would otherwise poison the consensus range. Any figure outside this band is discarded and the card falls back to fair_value_per_share = None.

When no JSON is found at all, a regex fallback scans the raw prose for currency-prefixed numbers, a stance keyword and a thesis sentence — rescuing a persona that answered narratively from producing an empty card.

Also used by _apply_deterministic_blend() → mean of crew + rule value None unless BOTH exist

3

Fallback path

_compute_fallback_aggregate

Under Process.sequential, a persona task that burns its retry budget can take the aggregator down with it. When the lead's output is missing or unparseable, the range is computed directly from the persona cards instead — and errors records that the fallback was used:

"Lead-analyst task produced no output; used a computed range."

AggregateResult.participating counts how many personas actually contributed a number. A low count means the range is thin, so the UI should surface it rather than advertising "4 of 4 investors agree". Note avg_fair_value is an unweighted mean — conviction is not used as a weight.

Implemented by aggregate_from_raw() or _compute_fallback_aggregate()

Notable behaviours

read before trusting output
LocationBehaviour
run_persona_crew() Task outputs are mapped back by Task.name. A persona whose name does not appear in tasks_output is treated as "produced no output" and gets an empty card — the mapping is name-based, not positional.
_apply_deterministic_blend() Cards are matched to PERSONAS positionally. That is safe only because run_persona_crew appends exactly one card per persona on every path (success, missing output, or parse failure).
_apply_deterministic_blend() blended_fair_value is the mean of crew and rule values, and is None unless both exist — a missing rule value must not silently drag the average toward zero.
_range_from_persona_values() mid is the midpoint of min and max, not the mean of the persona values. This replicates persona_super_valuation exactly so the two cannot drift apart.
aggregate_from_raw() avg_fair_value is an unweighted mean — conviction is collected per persona but never used as a weight.
deterministic_persona_values() Values come back in the company's reporting currency and are converted to the market-price currency via the to_currency argument. Without that conversion an INFY.NS comparison would be USD values against an INR price.
_memoise() Keys are built from repr(args) and sorted(kwargs.items()), which is only safe because every wrapped function takes plain strings. Results survive across run_persona_crew calls for the TTL window (default 900s).
persona_from_raw() emoji and image always come from PERSONAS, never from the LLM — so a persona cannot rebrand itself, and the card identity stays consistent.
Top-of-file ordering The UTF-8 stdout/stderr reconfiguration and OTEL_SDK_DISABLED must both run before import crewai. Moving the import block breaks Windows consoles with a 'charmap' codec error.
