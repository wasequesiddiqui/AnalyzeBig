◆
Every valuation function returns a tuple. For firm-level models (FCFF, APV, CCF, EVA, Sum-of-the-Parts) the first element is the enterprise value and the second is equity value per share after subtracting net debt. For equity-level models (DDM, FCFE, RIM, ECF) the first element is the equity value directly. Notation: D₀ dividend, r cost of equity, g growth, N shares outstanding.
01

Dividend Discount Models

equity-level · 4 functions

Gordon Growth Model

Equity
\[ P_0 \;=\; \frac{D_1}{r-g} \;=\; \frac{D_0\,(1+g)}{r-g} \qquad\text{requires } r > g \]

Constant perpetual dividend growth. The simplest DDM — one growth rate forever.

Implemented by ddm_gordon() → raises ValueError if r ≤ g

Two-Stage DDM

Equity
\[ P_0 \;=\; \sum_{t=1}^{n}\frac{D_0\,(1+g_1)^t}{(1+r)^t} \;+\; \frac{1}{(1+r)^n}\cdot\frac{D_n\,(1+g_2)}{r-g_2} \]

High-growth phase for n years, then a Gordon terminal value at stable growth g₂.

Implemented by ddm_two_stage() → requires r > g₂

Three-Stage DDM

Equity
\[ P_0 = \underbrace{\sum_{t=1}^{n_1}\frac{D_0(1+g_1)^t}{(1+r)^t}}_{\text{high growth}} + \underbrace{\sum_{i=1}^{n_2}\frac{D_{n_1+i-1}\,(1+g_i)}{(1+r)^{\,n_1+i}}}_{\text{linear transition}} + \underbrace{\frac{D_{n_1+n_2}\,(1+g_3)}{(r-g_3)\,(1+r)^{\,n_1+n_2}}}_{\text{terminal}} \]
\[ g_i \;=\; g_1 - i\cdot\frac{g_1-g_3}{n_2+1}, \qquad i = 1,\dots,n_2 \]

Growth decays linearly across the transition phase. Note the step divisor is n₂+1, so the last transition rate lands one notch above g₃ — the terminal value then applies g₃ permanently.

Implemented by ddm_three_stage() → requires r > g₃

H-Model

Equity
\[ P_0 \;=\; \frac{D_0\,(1+g_L)}{r-g_L} \;+\; \frac{D_0\,H\,(g_S-g_L)}{r-g_L} \]

Closed-form version of a linearly declining growth rate, where H is the half-life of the high-growth period — so the full high-growth phase spans 2H years. Cheaper than the three-stage loop.

Implemented by ddm_h_model() → requires r > g_L

Free Cash Flow to Firm

enterprise-level · discounted at WACC

FCFF — Single Stage

Enterprise
\[ EV = \frac{FCFF_1}{WACC-g} = \frac{FCFF_0\,(1+g)}{WACC-g} \] \[ V_0 = \frac{EV - D_{net}}{N} \]

Constant-growth perpetuity of unlevered free cash flow, then bridge from enterprise value to per-share equity value.

Implemented by fcff_single_stage() → requires WACC > g

FCFF — Two Stage

Enterprise
\[ EV \;=\; \sum_{t=1}^{n}\frac{FCFF_t}{(1+WACC)^t} \;+\; \frac{1}{(1+WACC)^n}\cdot\frac{FCFF_n\,(1+g_2)}{WACC-g_2} \]

Explicit forecast for n high-growth years followed by a stable-growth terminal value.

Implemented by fcff_two_stage() → requires WACC > g₂
03

Free Cash Flow to Equity

equity-level · discounted at r

FCFE — Constant Growth

Equity
\[ Equity = \frac{FCFE_1}{r-g} = \frac{FCFE_0\,(1+g)}{r-g} \]

Single-stage FCFE. No net-debt bridge is needed because the cash flow is already an equity claim.

Implemented by fcfe_constant_growth() → requires r > g

FCFE — Two Stage

Equity
\[ Equity \;=\; \sum_{t=1}^{n}\frac{FCFE_t}{(1+r)^t} \;+\; \frac{1}{(1+r)^n}\cdot\frac{FCFE_n\,(1+g_2)}{r-g_2} \]

Structurally identical to the two-stage FCFF model, but discounted at the cost of equity.

Implemented by fcfe_two_stage() → requires r > g₂
04

Adjusted Present Value

separates operating & financing value

APV

Enterprise
\[ V_L \;=\; V_U \;+\; PV(\text{tax shields}) \] \[ V_U \;=\; \sum_{t=0}^{m-1}\frac{FCFF_t}{(1+r_U)^{t+1}} \;+\; \frac{TV_U}{(1+r_U)^{n}}, \qquad TV_U = \frac{FCFF_{n-1}\,(1+g)}{r_U-g} \] \[ PV(TS) \;=\; \sum_{t=0}^{k-1}\frac{TS_t}{(1+r_{TS})^{t+1}} \]

Values the unlevered firm first, then adds the interest tax shield as a separate component. The tax shield may be discounted at a different rate (discount_rate_tax_shields, typically the cost of debt) than the operating cash flows. A terminal perpetuity on V_U is added only when terminal_growth > 0 and terminal_year equals the list length.

Implemented by apv() → rU = unlevered cost of equity rTS = tax-shield discount rate
05

Capital Cash Flow

tax shield folded into cash flow

CCF

Enterprise
\[ CCF_t \;=\; FCFU_t \;+\; T_c\cdot I_t \] \[ EV \;=\; \sum_{t=0}^{n-1}\frac{CCF_t}{(1+r_U)^{t+1}} \;+\; \frac{1}{(1+r_U)^{n}}\cdot\frac{CCF_{n-1}\,(1+g)}{r_U-g} \]

The mirror image of APV: instead of discounting the tax shield separately, it is added into each period's cash flow and the total is discounted at the unlevered cost of equity r_U. Note the flows are indexed from t=0 and discounted at t+1, i.e. year-1 cash flows are discounted one period.

Implemented by ccf() → requires r_U > g when g > 0
06

Equity Cash Flow

levered equity claim

ECF

Equity
\[ ECF \;=\; \text{Dividends} \;+\; \text{Share repurchases} \;-\; \text{New equity issued} \] \[ Equity \;=\; \sum_{t=0}^{n-1}\frac{ECF_t}{(1+r)^{t+1}} \;+\; \frac{1}{(1+r)^{n}}\cdot\frac{ECF_{n-1}\,(1+g)}{r-g} \]

The widest definition of an equity cash flow — captures dividends plus buybacks net of issuance.

Implemented by ecf() → requires r > g when g > 0
07

Residual Income & Economic Profit

book-value anchored

Residual Income Model (RIM)

Equity
\[ V_0 \;=\; B_0 \;+\; \sum_{t=1}^{n}\frac{RI_t}{(1+r)^t}, \qquad RI_t \;=\; NI_t \;-\; r\cdot B_{t-1} \] \[ TV_{RI} \;=\; \frac{RI_n\,(1+g)}{r-g}\Big/(1+r)^n \quad\text{when } g>0 \]

Anchored on the current book value of equity B₀, then adds the present value of profit earned above the cost of equity. Bₜ₋₁ is the beginning book value of period t — the previous year's ending book value. The final residual income is recomputed from the correct opening book value before applying terminal growth.

Implemented by residual_income() → book_values_forecast length must equal net_income_forecast

Economic Value Added (EVA)

Enterprise
\[ EV \;=\; IC_0 \;+\; \sum_{t=1}^{n}\frac{EVA_t}{(1+WACC)^t}, \qquad EVA_t \;=\; NOPAT_t \;-\; WACC\cdot IC_{t-1} \]

The enterprise-level twin of RIM: anchored on invested capital, then adds value created above the WACC hurdle. Uses beginning-period invested capital ICₜ₋₁ as the capital charge base, then subtracts net debt to reach equity.

Implemented by eva() → invested_capital_forecast length must match nopat_forecast

Sum-of-the-Parts

segment aggregation

Sum-of-the-Parts DCF

Enterprise
\[ EV \;=\; \sum_{i=1}^{k} V_i, \qquad V_0 \;=\; \frac{EV - D_{net}}{N} \]

Simply aggregates independently valued segments. In the orchestrator the two segments are themselves produced by calling fcff_single_stage() twice — splitting FCFF 60 / 40 across the two parts — which is the clearest cross-model linkage in the module.

Implemented by sum_of_the_parts() ← fed by 2× fcff_single_stage()

Real Options

scenario & optionality value

Decision Tree DCF

Option
\[ \mathbb{E}[NPV] \;=\; \sum_{i=1}^{k} p_i \cdot NPV_i, \qquad \sum_{i=1}^{k} p_i = 1 \]

Probability-weighted expected NPV. Probabilities are validated with np.isclose(…, 1.0). The discount_rate argument is accepted for interface consistency only and is never used — NPVs are assumed to already be discounted.

Implemented by decision_tree_dcf() → called by decision_tree_dcf_wrapper()

Real Option — Black-Scholes

Option
\[ C \;=\; S_0\,e^{-qT}\,N(d_1) \;-\; X\,e^{-rT}\,N(d_2) \]
\[ d_1 = \frac{\ln\!\left(S_0/X\right) + \left(r - q + \tfrac{\sigma^2}{2}\right)T}{\sigma\sqrt{T}}, \qquad d_2 = d_1 - \sigma\sqrt{T} \]

Treats a growth/expansion opportunity as a European call: S₀ is the present value of project cash flows, X the investment cost, and N(·) the standard normal CDF via scipy.stats.norm.cdf. Degenerates to intrinsic value max(S₀ − X, 0) when T ≤ 0. The resulting premium is meant to be added to a static NPV.

Implemented by real_option_black_scholes() → scipy.stats.norm.cdf

Stochastic & Simulation Models

distribution-based

Monte Carlo DCF

Simulation
\[ g_t \sim \mathcal{N}\!\left(\mu,\;\sigma^2\right), \qquad CF_t = CF_{t-1}\,(1+g_t) \]
\[ PV^{(j)} \;=\; \sum_{t=1}^{T}\frac{CF_t^{(j)}}{(1+r)^{t}} \;+\; \frac{1}{(1+r)^{T}}\cdot\frac{CF_T^{(j)}\,(1+g)}{r-g}, \qquad \mathbb{E}[NPV] = \frac{1}{J}\sum_{j=1}^{J} PV^{(j)} \]

Simulates J paths of uncertain annual growth, discounts each to a present value, and returns the mean alongside the full distribution array. The RNG is seeded with np.random.seed(42), so results are deterministic and reproducible between runs.

Implemented by monte_carlo_dcf() → called by monte_carlo_dcf_wrapper() numpy

Certainty-Equivalent DCF

Simulation
\[ V_0 \;=\; \sum_{t=1}^{n}\frac{\alpha_t \,\mathbb{E}[CF_t]}{(1+r_f)^{t}}, \qquad 0 < \alpha_t \le 1 \]

Adjusts the numerator for risk instead of the discount rate: risky expected cash flows are scaled down by certainty-equivalent coefficients αₜ and then discounted at the risk-free rate. The wrapper subtracts net debt only when is_enterprise=True, since the same function serves both FCFF and equity cash flows.

Implemented by certainty_equivalent_dcf() → called by certainty_equivalent_dcf_wrapper() requires len(α) == len(CF)

Input Derivation

get_financial_data()

Cash-flow & profit definitions

Inputs
\[ FCFF \;=\; EBIT\,(1-t) \;+\; \text{Dep} \;-\; \text{CapEx} \;-\; \Delta WC \]
\[ FCFE \;=\; FCFF \;-\; \text{Interest}\,(1-t) \;+\; \text{Net Borrowing} \]
\[ NOPAT \;=\; EBIT\,(1-t) \]

Dep is depreciation & amortisation. CapEx is normalised with abs() because yfinance reports it as a negative number. Net Borrowing is not modelled and ΔWC is a hard-coded placeholder of 0 — worth knowing when reconciling the output against a hand-built model.

Discount rates & capital structure

Inputs
\[ r_e \;=\; r_f \;+\; \beta \cdot MRP \qquad (r_f = 4\%,\; MRP = 5\%) \]
\[ r_d \;=\; \frac{\text{Interest Expense}}{\text{Total Debt}} \qquad(\text{fallback } 4\%) \]
\[ WACC \;=\; \frac{r_e\,E \;+\; r_d\,(1-t)\,D}{E + D} \]
\[ D_{net} = \text{Total Debt} - \text{Cash}, \qquad IC_0 = \text{Total Debt} + B_0 \]

Equity E uses market capitalisation, not book equity. The risk-free rate and market risk premium are fixed placeholders rather than market-sourced values.

Effective tax rate

Inputs
\[ t \;=\; \frac{\text{Income Tax Expense}}{\text{Pretax Income}} \qquad(\text{fallback } 0.21) \]

Falls back to the 21% US statutory rate when either figure is unavailable or pretax income is zero.

Scenario Forecast Engine

run_valuation_analysis()

Projection recursions

Orchestrator
\[ FCFF_t = FCFF_{t-1}(1+g_{fcff}), \qquad D_t = D_{t-1}(1+g_{div}), \qquad NI_t = NI_{t-1}(1+g_{ni}) \]
\[ B_t \;=\; B_{t-1} + 0.4\,NI_t \qquad (\text{40\% retention}) \]
\[ NOPAT_t \;=\; NOPAT_{t-1}(1+g_{fcff}), \qquad IC_t \;=\; IC_{t-1} + 0.5\,NOPAT_t \]
\[ TS_t \;\approx\; 0.02 \cdot FCFF_t, \qquad \alpha_t = 0.85 \;\; \forall t \]

Book value and invested capital are grown by simplified reinvestment rates rather than derived from a real capital plan, and tax shields are approximated as a flat 2% of FCFF rather than from an interest schedule.

Stable-growth clamping

Orchestrator
\[ g_{stable}^{eq} \;=\; \min\!\left(g_{stable},\; 0.9\,r_e\right), \qquad g_{stable}^{wacc} \;=\; \min\!\left(g_{stable},\; 0.9\,WACC\right) \]

Guards the r > g precondition that every perpetual-growth model requires. Scenario g_stable values are clamped to at most 90% of the relevant discount rate before being passed to the models — without this, a bull-case growth rate could exceed the discount rate and raise ValueError.

Aggregation

Orchestrator
\[ \bar{V}_{scenario} = \frac{1}{k}\sum_{i=1}^{k} V_i, \qquad \bar{V}_{all} = \frac{1}{m}\sum_{j=1}^{m} V_j \]

Each scenario is the unweighted mean of 21 per-share estimates, and the headline figure is the mean across all scenarios pooled together. No model weighting, trimming or outlier treatment is applied.

Notable behaviours

read before trusting output
LocationBehaviour
run_valuation_analysis · "9b" The Black-Scholes block appends the previous scenario value (vps) to scenario_vps rather than the computed option_val. The option premium is printed but never enters any average — so the DDM value above it is counted twice.
decision_tree_dcf discount_rate is accepted and ignored; the wrapper passes 0.0. NPVs must already be discounted by the caller.
monte_carlo_dcf Calls np.random.seed(42) internally, so it is reproducible but also mutates global RNG state for anything running after it.
get_financial_data change_in_wc = 0 placeholder and no net-borrowing term — both WC and net borrowing are effectively omitted from FCFF / FCFE.
residual_income last_ri is computed three times in the terminal-value block; the first two assignments are dead code. The final, correct value uses the right opening book value.
run_valuation_analysis segment_values calls fcff_single_stage() with net_debt = 0 deliberately, so the returned first element is a pure segment enterprise value. If it ever returned equity value instead, SOTP would silently double-count the debt bridge.
All occurrences Discount rates, betas and growth assumptions come from fixed constants or yfinance fields — yfinance's beta is unreliable for non-US listings (e.g. INFY.NS returns ≈ 0.11), which flows straight into the CAPM cost of equity.
