This module is the deterministic, rule-based counterpart to the agentic crewAI personas. Each persona is a closed-form valuation rule computed from the same yfinance financial statements — no LLM, no network calls beyond the data fetch, fully reproducible. All values are returned in the company's reporting currency, which may differ from its trading currency.

Probability-weighted average of three growth scenarios, with the terminal value faded toward WACC via a reinvestment rate.

B

Shared input pipeline

computed once, used by all four rules

Statement extraction

Shared
\[ \text{NWC} = \big(\text{Current Assets} - \text{Cash}\big) - \big(\text{Current Liabilities} - \text{Short-Term Debt}\big) \]
\[ D_{total} = D_{short} + D_{long}, \qquad B_0 = \text{Total Stockholder Equity} \]

Fetched through _get_fin(), which walks a list of candidate row labels and returns the first non-NaN value. yfinance labels vary widely by listing, so D&A is looked up on the income statement first (Reconciled Depreciation) then the cash flow statement. Missing debt rows fall back to 0.0; CapEx is normalised with abs() because Yahoo signs it negative.

Normalised ratios

Shared
\[ \text{ebit\_margin} = \frac{EBIT}{Rev},\quad \text{depr\_ratio} = \frac{Dep}{Rev},\quad \text{capex\_ratio} = \frac{CapEx}{Rev},\quad \text{nwc\_ratio} = \frac{NWC}{Rev} \]

Every ratio goes through the NaN-aware _ratio() helper, which returns a default when either input is missing or the denominator is zero — defaults are 0.15 · 0.03 · 0.03 · 0.10 respectively.

Cost of capital

Shared
\[ k_e = r_f + \beta \cdot MRP, \qquad k_d = \frac{\text{Interest Expense}}{D_{total}} \quad(\text{fallback } 0.045) \]
\[ WACC = \frac{E}{E + D}\,k_e \;+\; \frac{D}{E + D}\,k_d\,(1 - t) \]
\[ \beta_u = \frac{\beta}{1 + (1-t)\,\frac{D}{E}}, \qquad k_u = r_f + \beta_u \cdot MRP \]

Country-aware inputs: r_f = 0.04 and MRP = 0.05 by default, but r_f = 0.065 and MRP = 0.06 when info['country'] contains "india". Note the canonical WACC is computed with book equity here (not market cap, unlike ALL_DCF_MODELS), and it is never used by the Buffett rule — only by Munger, Jhunjhunwala and Damodaran.

Tax, growth & returns

Shared
\[ t = \frac{\text{Tax Provision}}{NI + \text{Tax Provision}} \quad(\text{fallback } 0.21) \]
\[ ROE = \frac{NI}{B_{prev}}, \qquad ROIC = \frac{EBIT\,(1-t)}{\text{Total Assets} - \text{Cash} + NWC} \]
\[ g_{term} = \min(r_f,\; 0.025), \qquad g_{rev} = \text{clamp}\big(\text{revenueGrowth},\; 0,\; 0.30\big) \]

revenueGrowth is a quarterly year-over-year figure used as a long-run proxy; it falls back to 0.05 when NaN or below −50%, then is clamped to the 0–30% band. B_prev is the prior year's equity, reconstructed as equity − NI + dividends paid when unavailable.

Public API

two thin wrappers over one engine
FunctionReturnsUse when
persona_super_valuation() (min, max, midpoint) or (None, None, None) You want the collapsed range. Note midpoint is (min+max)/2, not the mean of the four values.
persona_valuations() dict with all four names, values or None You want each persona separately — e.g. to compare or blend against the crewAI result.

Both call the same _persona_prices() engine, so the range and the per-persona figures can never disagree. Per-persona keys are ordered by PERSONA_RULE_NAMES and are always present — a rule that didn't price maps to None rather than being omitted.

D

Behaviour worth knowing

shapes the output you see
MechanismEffect
if val > 0 filter A persona is only reported when its per-share value is positive. A rule that computes zero or a negative value is silently dropped from the list — which is why the range can be built from fewer than four personas.
Degenerate range When only one rule survives, min == max == midpoint. The UI treats fewer than two priced personas as degenerate and hides the comparison panel.
Reporting currency Values are in the company's reporting currency (USD for INFY.NS), which can differ from its trading currency. Convert before comparing with a market price.
Never raises Any failure — including all four rules failing — is caught, printed as Error for <ticker>, and returned as an empty list. Callers always get a usable value.

Warren Buffett

Owner Earnings 10-year DCF

"A wonderful business at a fair price" — value the owner's cash, demand a margin of safety, and refuse to pay for perfection.

1

The rule

buffett_price()
\[ OE_0 \;=\; NI \;+\; \text{Dep} \;-\; 0.8 \cdot \text{CapEx} \;-\; 0.01 \cdot \text{nwc\_ratio} \cdot \text{Rev} \]
\[ OE_t = OE_0\,(1+g_B)^t \qquad\text{and}\qquad PV_{OE} = \sum_{t=1}^{10} \frac{OE_t}{(1+r_B)^t} \]
\[ TV = \frac{OE_{10}\,(1+g_B)}{(r_B - g_B)\,(1+r_B)^{10}} \qquad V_0 = \frac{\big(PV_{OE} + TV\big)\,(1 - MoS)}{N} \]
2

Constants & assumptions

hard-coded
\[ r_B = r_f + 0.02 \qquad g_B = \min(r_f,\; 0.02) \qquad MoS = 0.25 \qquad T_{explicit} = 10 \]
SymbolMeaning
r_BDiscount rate — the risk-free rate plus a flat 2% moat premium. Note this ignores the computed WACC and beta entirely.
g_BPerpetual growth, capped at the risk-free rate and at 2%.
MoS25% margin of safety, applied to the whole intrinsic value before dividing by shares.
0.8 · CapExOnly 80% of capital expenditure is charged against earnings — a proxy for growth capex being discretionary.
3

Confidence index

buffett_pci
\[ PCI_{Buffett} \;=\; \text{moat} \cdot \text{stability} \cdot \text{mgmt} \cdot \text{leverage} \]
moat
1.0 / 0.6
1.0 when EBIT margin > 20%, ROE > 15% and D/E < 0.5; else 0.6.
stability
0.8
Fixed placeholder — free-cash-flow stability is not actually measured.
mgmt
0.9 / 0.7
0.9 when ROE > 12%, else 0.7. A crude management-quality proxy.
leverage
1.0 / 0.5
1.0 when total debt / equity < 0.5, else 0.5.

The PCI is computed but not used in the price formula above — it is reported alongside the value as a qualitative confidence score.

Charlie Munger

Residual Income Moat-truncated

"The big money is not in the buying and selling, but in the waiting" — pay for quality that compounds above its cost of capital, and only for as long as the moat lasts.

1

The rule

munger_price()
\[ NI_t = NI_1\,(1+g_{term})^{\,t-1}, \qquad RI_t = NI_t - r_M \cdot B_{t-1} \]
\[ B_t = B_{t-1} + NI_t\,(1 - 0.20) \qquad\text{(20\% assumed payout)} \]
\[ V_0 = \frac{1}{N}\left( B_{prev} + \sum_{t=1}^{T} \frac{RI_t}{(1+r_M)^t} \right) \]
\[ T = \begin{cases} \min\!\big(20,\; \max(5,\; \lfloor (ROIC - WACC)\cdot 10 \rfloor)\big) & ROIC > WACC \\[4pt] 5 & \text{otherwise}\end{cases} \]

The horizon T is the estimated moat duration: the wider the excess return over WACC, the longer residual income is assumed to persist. There is no terminal value beyond T — the model simply stops.

2

Constants & assumptions

hard-coded
\[ r_M = 0.12 \qquad \text{payout} = 0.20 \qquad T \in [5, 20] \]
SymbolMeaning
r_MA flat 12% equity charge — deliberately fixed and independent of the computed cost of equity.
B_prevOpening book value. Reconstructed as equity − NI + dividends paid when the prior-year column is missing or non-positive.
payout20% of net income distributed, so 80% compounds into book value.
D&ANot used at all. This is the only one of the four rules that never reads depr — which is why it historically kept working when the others were dropped by NaN propagation.
3

Confidence index

munger_pci
\[ PCI_{Munger} \;=\; \max\Big(0.1,\;\; \text{premium} \cdot \text{duration} \cdot \text{assetLight} \cdot \text{pessimism} \Big) \]
premium
max(0, (ROIC − WACC) / WACC)
How large the excess return is, scaled by WACC.
duration
min(1, (ROIC − WACC) × 3) → 0.1
Proxy for how long the moat persists; 0.1 when ROIC ≤ WACC.
assetLight
1.0 / 0.6
1.0 when depreciation is under 5% of revenue, else 0.6.
pessimism
0.8
Fixed placeholder.

Unlike the other three, this PCI is floored at 0.1 so it can never collapse to zero. As with Buffett, it is reported rather than fed into the price.

Rakesh Jhunjhunwala

Three-stage FCFF India tailwind

"Invest in growth" — buy the compounding runway, and accept that the terminal state of a high-growth business is still a growing one.

1

The rule

jhunjhun_price()
\[ FCFF_0 \;=\; EBIT\,(1-t) \;+\; \text{Dep} \;-\; \text{CapEx} \;-\; 0.05 \cdot \text{nwc\_ratio} \cdot \text{Rev} \]
\[ \text{Stage 1 } (t = 1 \dots 5): \quad FCFF_t = FCFF_{t-1}(1+g_H) \]
\[ \text{Stage 2 } (t = 6 \dots 10): \quad \phi_t = \frac{t - 5}{10 - 5}, \qquad g_t = g_H\,(1 - \phi_t) + g_S\,\phi_t \]
\[ PV = \sum_{t=1}^{10} \frac{FCFF_t}{(1+WACC)^t}, \qquad TV = \frac{FCFF_{10}\,(1+g_S)}{(WACC - g_S)(1+WACC)^{10}} \]
\[ V_0 = \frac{PV + TV - \big(D_{total} - \text{Cash}\big)}{N} \]

This is the only rule with a genuine three-stage structure: 5 years at a constant hyper-growth rate, a 5-year linear glide path, then a stable perpetuity.

2

Constants & assumptions

country-aware
\[ g_H = \min(0.30,\; g_{rev} + 0.05) \qquad g_S = \begin{cases} 0.07 & \text{India} \\ 0.05 & \text{otherwise}\end{cases} \]
SymbolMeaning
g_HHyper-growth: observed revenue growth plus a flat 5 percentage-point optimism adder, capped at 30%.
g_SStable growth — 7% for Indian listings, 5% elsewhere. Detected from info['country'].
WACCThe only multi-stage rule that discounts at the computed WACC from book equity and beta.
0.05 · NWCWorking-capital drag is scaled by 5% — higher than Damodaran's 3%, reflecting a growth-company reinvestment view.

Aswath Damodaran

Scenario FCFF ROIC fade

"Valuation is a story, but the story must be quantified" — value the distribution of outcomes, and let excess returns fade toward the cost of capital.

1

The rule

damodaran_price()
\[ FCFF_0 \;=\; EBIT\,(1-t) \;+\; \text{Dep} \;-\; \text{CapEx} \;-\; 0.03 \cdot \text{nwc\_ratio} \cdot \text{Rev} \]
\[ \text{Scenario } i:\;\; g_i = \bar{g} + s_i\,\sigma_g, \qquad s_i \in \{-0.5,\;0,\;+0.5\}, \qquad p_i = \{0.25,\;0.50,\;0.25\} \]
\[ PV_i = \sum_{t=1}^{10} \frac{FCFF_0 \prod_{k=1}^{t}(1+g_i)}{(1+WACC)^t} \]
\[ ROIC_{term} = WACC + 0.02, \qquad RR = \frac{g_{term}}{ROIC_{term}}, \qquad TV_i = \frac{FCFF_{10}\,(1+g_{term})\,(1 - RR)}{WACC - g_{term}} \]
\[ V_0 \;=\; \sum_{i=1}^{3} p_i \cdot \max\!\left(0,\;\; \frac{PV_i + \dfrac{TV_i}{(1+WACC)^{10}} - \big(D_{total} - \text{Cash}\big)}{N}\right) \]

The terminal value uses a reinvestment-rate fade: as ROIC converges toward WACC plus a 2-point residual, the fraction of cash flow that must be reinvested (RR) rises, cutting the terminal cash flow. Growth is then probability-weighted rather than assumed.

2

Constants & assumptions

hard-coded
\[ \sigma_g = 0.08 \qquad n_{scenarios} = 3 \qquad ROIC_{term} = WACC + 0.02 \qquad T_{explicit} = 10 \]
SymbolMeaning
σ_gGrowth dispersion. Only ±0.5σ is sampled, so the scenarios span just ±4 percentage points of growth.
WACCComputed from book equity and beta, as in the Jhunjhunwala and Munger rules.
0.03 · NWCWorking-capital drag at 3% — lower than Jhunjhunwala's 5%.
max(0, …)Each scenario is floored at zero before weighting, so a deeply negative scenario cannot pull the expected value below zero.
3

The only persona whose confidence is a flat value for any real company — no conditioning on margins, returns or leverage.

Notable behaviours

read before trusting output
LocationBehaviour
damodaran_price() Each scenario computes sc['marg'] (a stressed/relaxed EBIT margin) but the projection loop only reads sc['g']. The margin differentiation is never applied — the three scenarios differ only by growth rate.
buffett_price() Discounts at r_f + 0.02 and grows at min(r_f, 0.02). Because g_B ≤ r_B always holds, the terminal value is always finite — this rule can never divide by zero.
_persona_prices() The if val > 0 guard is deliberate and preserved. It means the range and per-persona values always agree, but also that a rule producing a negative value vanishes rather than reporting a bearish view.
persona_super_valuation() Returns (min+max)/2 as the third element, not the mean of the four persona values. With only two survivors this coincides; with three or four it does not.
_ratio() Lives inside _persona_prices(), so it is re-created on every call. It exists specifically to stop a single missing yfinance row from NaN-propagating into three of the four rules.
WACC vs k_e Two different capital costs coexist: wacc (book-equity weighted, used by Munger / Jhunjhunwala / Damodaran) and the fixed r_M = 0.12 and r_B = r_f + 0.02 used by Munger and Buffett respectively. They are not reconciled.
_get_fin() idx Defaults to column index 0 — the most recent year. Only int_exp is passed explicitly with idx=0; equity_prev uses idx=1.
