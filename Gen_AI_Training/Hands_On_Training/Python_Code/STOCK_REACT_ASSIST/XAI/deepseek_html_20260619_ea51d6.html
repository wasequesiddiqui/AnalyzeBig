1. Introduction

This interactive tutorial walks you through building an explainable credit‑risk assessment system using DeepSeek (as the rule‑generating and explaining LLM) and DeepEval (for rigorous evaluation).

You will:

  • Preprocess and binarize the German Credit dataset.
  • Prompt DeepSeek to produce interpretable Boolean rules.
  • Find similar past applicants (prototypes) and generate contrastive “what‑if” explanations.
  • Evaluate everything with custom DeepEval metrics.
  • Interpret results from three perspectives: Data Scientist, Loan Officer, Consumer.
⚠️ To execute the code, you need a Python environment with the packages openai, pandas, scikit‑learn, ucimlrepo, and deepeval, plus a valid DeepSeek API key.

5. Boolean Rule Generation with DeepSeek

We provide a few training examples to DeepSeek and ask for interpretable rules in JSON format.

def generate_rules_with_deepseek(X_sample, y_sample, feature_names, previous_rules=None, feedback=''):
    sample_text = ""
    for idx, row in X_sample.iterrows():
        features_str = "; ".join([f"{col}={row[col]}" for col in feature_names if row[col]==1])
        label = "bad" if y_sample.loc[idx]==1 else "good"
        sample_text += f"Example {idx}: {features_str} → {label}\n"

    system_prompt = """You are a credit risk expert... (full prompt)"""
    user_prompt = f"""...Examples:
{sample_text[:3000]}
Generate the best Boolean rules... Output JSON only."""

    messages = [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_prompt}
    ]
    response = deepseek_client.chat.completions.create(
        model="deepseek-chat",
        messages=messages,
        temperature=0.2,
        max_tokens=1000,
    )
    raw = response.choices[0].message.content
    # Parse JSON (handle possible markdown fences)
    if '```json' in raw:
        json_str = re.search(r'```json\s*(.*?)\s*```', raw, re.DOTALL).group(1)
    else:
        json_str = raw
    return json.loads(json_str)

Now apply the rules to the test set:

def apply_rules(rules_dict, X):
    pred = np.zeros(len(X), dtype=int)
    for rule in rules_dict['rules']:
        mask = np.ones(len(X), dtype=bool)
        for cond in rule['conditions']:
            feat = cond['feature']
            val = cond['value']
            if feat in X.columns:
                if val == 1:
                    mask = mask & (X[feat] == 1)
                else:
                    mask = mask & (X[feat] == 0)
            else:
                mask = np.zeros(len(X), dtype=bool)
                break
        pred = pred | mask.astype(int)
    return pred

y_test_pred = apply_rules(rules_data, X_test)
print("Accuracy:", accuracy_score(y_test, y_test_pred))
print("Recall (bad):", recall_score(y_test, y_test_pred))

6. DeepEval Integration – Rule Faithfulness

We define a custom metric that checks each rule against actual data using an LLM judge (DeepSeek).

from deepeval.metrics import BaseMetric
from deepeval.test_case import LLMTestCase

class RuleFaithfulnessMetric(BaseMetric):
    def __init__(self, threshold=0.5):
        self.threshold = threshold
        self.score = None
        self.reason = ""

    def measure(self, test_case: LLMTestCase):
        rule_desc = test_case.input
        context = test_case.context  # list of example strings
        prompt = f"""Evaluate this credit rule: "{rule_desc}"
Given these examples:
{context}
Does the rule hold? Answer YES/NO and explain."""
        resp = deepseek_client.chat.completions.create(
            model="deepseek-chat",
            messages=[{"role": "user", "content": prompt}],
            temperature=0
        )
        ans = resp.choices[0].message.content
        self.reason = ans
        self.score = 1.0 if 'YES' in ans.upper() else 0.0
        self.success = self.score >= self.threshold
        return self.score

# Evaluate each rule
for rule in rules_data['rules']:
    # Build context from a few fired examples...
    tc = LLMTestCase(input=rule['description'], actual_output="bad", context=[...])
    metric = RuleFaithfulnessMetric()
    metric.measure(tc)
    print(f"Rule: {rule['description']} → Faithful? {metric.score:.2f}")

10. Full Evaluation Suite

Assemble multiple test cases and run DeepEval’s evaluate function.

from deepeval import evaluate
from deepeval.dataset import EvaluationDataset
from deepeval.metrics import CorrectnessMetric

test_cases = []
for idx in X_test.index[:10]:
    pred = apply_rules(rules_data_v2, pd.DataFrame([X_test.iloc[idx]]))[0]
    tc = LLMTestCase(
        input=X_test.iloc[idx].values.tolist(),
        actual_output=str(pred),
        expected_output=str(y_test[idx]),
    )
    test_cases.append(tc)

dataset = EvaluationDataset(test_cases=test_cases)
results = evaluate(dataset, metrics=[CorrectnessMetric()], write_cache=False)
print(results)
