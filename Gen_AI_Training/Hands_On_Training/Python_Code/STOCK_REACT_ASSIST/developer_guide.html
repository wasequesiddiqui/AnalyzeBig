Stock React Assistant

A LangChain ReAct agent that researches stocks autonomously — fetching news, analysing financial impact with DeepSeek, and gauging Twitter sentiment with a RoBERTa transformer.

🏗️ Architecture Overview

The agent follows the ReAct (Reasoning + Acting) paradigm. The LLM alternates between internal reasoning ("Thought") and tool invocation ("Action") until it has enough information to produce a "Final Answer".

🔁 AgentExecutor

Orchestrates the ReAct loop. Parses the LLM's output, dispatches tool calls, feeds observations back, and stops when a Final Answer is produced — or after max_iterations=6.

🧰 Tools

Three @tool-decorated Python functions. Each tool's docstring is its prompt — the LLM reads it to decide which tool to use and what arguments to pass.

📋 Prompt Template

A classic ReAct-format template with placeholders {tool_names}, {input}, and {agent_scratchpad}. The scratchpad accumulates the Thought/Action/Observation history.

🔧 The Three Tools

Each @tool function is an independent capability the agent can invoke. Click each card to expand implementation details.

📰 get_stock_news Tool 1

Queries NewsAPI's /v2/everything endpoint for the 10 most recent English-language business articles matching the stock ticker.

@tool def get_stock_news(ticker: str) → str
Inputticker: str — e.g. "AAPL"
OutputNumbered list of headlines + descriptions
APINewsAPI free tier (500 req/day)
Error handlingReturns "Error fetching news: …" so the agent can observe and adapt

📊 analyze_impact Tool 2

Takes raw news text and prompts DeepSeek to produce a structured JSON analysis covering four financial dimensions.

@tool def analyze_impact(news_text: str) → str
Inputnews_text: str — concatenated headlines from get_stock_news
OutputPretty-printed JSON with keys: financials, business_growth, cashflows, profitability
LLMChatDeepSeek @ temperature=0 (deterministic)
FallbackIf JSON parsing fails, returns raw LLM text

🐦 get_twitter_sentiment Tool 3

Scrapes tweets via snscrape (no API key required) and classifies sentiment using a RoBERTa transformer fine-tuned on ~124M tweets.

@tool def get_twitter_sentiment(ticker: str) → str
Inputticker: str — prefixed with $ for cashtag search
Window90 days (quarterly cadence)
ScrapeUp to 200 tweets; first 100 classified
Modelcardiffnlp/twitter-roberta-base-sentiment-latest
OutputPercentage breakdown: positive / neutral / negative

🤖 Agent Configuration

How the ReAct loop is wired together and what each parameter controls.

📋 ReAct Prompt Template

The prompt structure is critical — the AgentExecutor uses regex to find Action: and Action Input: lines. Any deviation breaks the parser.

Question: the input question you must answer
Thought:  you should always think about what to do
Action:  the action to take, should be one of [{tool_names}]
Action Input: the input to the action
Observation: the result of the action
... (repeat as needed)
Thought: I now know the final answer
Final Answer: the final answer to the original input question

⚙️ AgentExecutor Parameters

ParameterValuePurpose
agentReAct runnableThe wired-up LLM + tools + prompt
tools[get_stock_news, …]Tool list for dispatch
verboseTruePrints Thought/Action/Observation to console
handle_parsing_errorsTrueFeeds malformed LLM output back as an Observation so the agent can self-correct
max_iterations6Hard safety cap — prevents infinite loops

🔄 Execution Flow (Step by Step)

1.User calls agent_executor.invoke({"input": question})
2.AgentExecutor fills the prompt template with {input} and sends it to the LLM
3.LLM generates Thought: … Action: get_stock_news Action Input: AAPL
4.Executor parses the Action line, calls get_stock_news("AAPL"), and appends the result as an Observation
5.Loop repeats — the updated scratchpad is sent back to the LLM for the next Thought/Action
6.LLM outputs Final Answer: … → AgentExecutor stops and returns {"output": "…"}

🚀 Setup & Run

Get the agent running in under 5 minutes.

1️⃣ Environment Variables

Create a .env file in the project root:

DEEPSEEK_API_KEY=sk-your-key-here
NEWS_API_KEY=your-newsapi-key

2️⃣ Install Dependencies

pip install langchain langchain-core langchain-deepseek
pip install python-dotenv newsapi-python snscrape
pip install transformers pandas

3️⃣ Run the Agent

python stock_react_agent.py
Enter stock ticker: AAPL
💡 Tip: First run will download the RoBERTa model (~500 MB). Subsequent runs use the cached model.
⚠️ Rate Limits: NewsAPI free tier allows 500 requests/day. snscrape may be rate-limited by Twitter/X if you scrape too aggressively. The 90-day window + 200-tweet cap is designed to stay within reasonable limits.
